**[VidMind-AI - 长视频内容理解 Video Agent 平台]**
:::
**[2026.03 - 2026.06]**
::: end

**技术栈**：`Java 21` `Spring Boot 3` `Vue 3` `MySQL 8` `Redis 7` `RocketMQ` `MinIO` `Qdrant` `LangChain4j` `DeepSeek` `FFmpeg` `Tesseract OCR`

**项目简介**：开源 Video Agent 平台，将长视频转化为可检索、可追溯、可追问的结构化知识。融合 ASR 与关键帧 OCR 构建多模态时序上下文，通过 Planner-Executor-Critic 多轮 Agent 编排完成用户分析目标。

- **设计多模态 VideoContext 流水线**：FFmpeg 按 60s 切分音频，基于场景变化检测抽取关键帧，30s 保底采样避免遗漏静态板书；ASR 与 OCR 线程池并行执行，感知哈希去重，单路失败时保留另一路有效信息，保障多模态解析鲁棒性。
- **构建受控 AgentLoop 编排器**：Planner 拆解用户目标为子任务，Executor 生成结构化结论与时间戳证据，Critic 校验覆盖完整性与证据可靠性；未通过时定向补充检索，最多两轮收敛，平衡修正能力与 Token 成本。
- **实现长视频检索与断点恢复**：每 5min 生成片段摘要、关键词与 Embedding，融合关键词匹配与 Qdrant 语义召回选取 TopK 证据；Qdrant 不可用时降级至本地关键词排序。MySQL 持久化 + Redis 热缓存全链路 Checkpoint，前端 SSE 实时推送阶段状态，支持断点续跑与失败任务重投。
- **设计高并发异步任务链路**：5MB 分片上传，Redis 追踪分片进度，MinIO 合并存储；RocketMQ 异步削峰，Redisson 基于内容指纹实现消费幂等；用户级与全局令牌桶双重限流，ASR 及模型调用引入指数退避重试，保障高负载下的系统稳定性。
- **主导全栈开发与架构设计**：独立完成 Spring Boot 后端（鉴权、分片上传、任务编排、Agent 推理、向量检索）、Vue 3 前端工作台（SSE 实时进度、Agent 交互面板）及 Docker Compose 中间件编排。
